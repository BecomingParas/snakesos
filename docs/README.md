Documents are organized by topic and phase. Most documents follow this naming convention:

- `*_COMPLETE.md` - Completion summaries
- `*_GUIDE.md` - Step-by-step guides
- `*_STATUS.md` - Current status reports
- `README_*.md` - Topic-specific readme files
- `QUICK_*.md` - Quick reference guides
