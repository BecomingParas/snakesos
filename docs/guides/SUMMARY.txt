OPTION A: AUTOMATIC (Recommended)
──────────────────────────────────

1. Right-click PowerShell → Run as Administrator

2. Run these commands:
   cd ~/OneDrive/Desktop/snake-rescue
   Set-ExecutionPolicy Bypass -Scope Process -Force
   .\setup-mobile-access.ps1

3. Follow on-screen instructions


OPTION B: MANUAL (If script doesn't work)
──────────────────────────────────────────

1. Edit apps/frontend/project.json
   Add this line: "hostname": "0.0.0.0"

2. Open Windows Firewall (Run as Admin):
   netsh advfirewall firewall add rule name="Next.js Dev Server" dir=in action=allow protocol=TCP localport=4200
   netsh advfirewall firewall add rule name="Backend GraphQL Server" dir=in action=allow protocol=TCP localport=4000

3. Start dev server:
   npm run dev

4. Access from mobile:
   http://192.168.1.65:4200

⚠️ COMMON ISSUES

Issue: "Can't access from mobile"
→ Check same Wi-Fi network
→ Restart dev server
→ Verify IP hasn't changed (run ipconfig)

Issue: "Firewall blocking"
→ Run setup script as Administrator
→ Or manually add firewall rules

Issue: "IP address changed"
→ Run ipconfig to get new IP
→ Update mobile URL with new IP
