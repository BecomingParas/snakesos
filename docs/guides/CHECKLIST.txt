  Problem: Mobile browser says "Can't connect"
  ──────────────────────────────────────────────
  [ ] Both devices on same Wi-Fi? Double-check!
  [ ] Dev server running? Look at terminal
  [ ] Restart dev server:
      [ ] Press Ctrl+C in terminal
      [ ] Type: npm run dev
      [ ] Wait for "ready"
      [ ] Try mobile again

  Problem: Setup script failed
  ──────────────────────────────
  [ ] Did you run PowerShell as Administrator?
  [ ] Try running the script again
  [ ] Or do manual firewall setup (see guide)

  Problem: IP address changed
  ──────────────────────────────
  [ ] Run: ipconfig
  [ ] Find new IPv4 Address
  [ ] Use new IP in mobile browser

  Problem: Wrong IP showing
  ──────────────────────────────
  [ ] Run: ipconfig
  [ ] Look for "Wireless LAN adapter Wi-Fi"
  [ ] Find "IPv4 Address" under that section
  [ ] Should be like: 192.168.x.x or 10.x.x.x
